# Архітектура: інструменти та будівлі

Усе, чим гравець взаємодіє зі світом, — це **piece** (елемент): або **tool**
(інструмент), або **building** (будівля). Один елемент = один файл, який описує
його повністю: HUD, ціну, рівні, звуки, поведінку. Ядро гри нічого не знає про
конкретні елементи — воно обходить реєстр `PIECES`.

## Карта файлів

```
js/lib/Shape.js                    SHAPES: line, slope, rect, circle → пул клітин
js/PlayerInteract/Registry.js      PIECES, PIECE_IDS, regPiece, regTool, хуки reset/tick/drawWorld
js/PlayerInteract/Build.js         рушій будівництва: regBuilding, drag, план, перевірка, стирання, прев'ю
js/PlayerInteract/Toolbelt.js      що відкрито, рівні, покупка й апгрейд, хотбар, меню E
js/PlayerInteract/Tools/*.js       Drill, Hand, Ignite
js/PlayerInteract/Buildings/*.js   Pad, Belt, Wall
```

Порядок `<script>` у `index.html` **є порядком елементів** в інвентарі та
стартових слотах. `tools/build-app.js` бере список файлів із `index.html`, тож
реєструвати файл у двох місцях не треба.

## Shape — спільний словник форм

`SHAPES[name](from, to, opt)` повертає масив клітин `{x, y}`. Форми не знають,
хто їх викликає: їх використовують і будівлі (план будівництва), і
інструменти (бур — `circle`, запал — `rect`).

| Форма | Результат | `opt` |
|---|---|---|
| `line` | горизонталь / 45° / (вертикаль) | `vertical` |
| `slope` | пряма під довільним кутом | — |
| `rect` | заповнений прямокутник | `even` — квадрат |
| `circle` | заповнений диск, центр = `from`, радіус = до `to` | — |

Нова форма — один рядок в `SHAPES` + ключ `shape.<name>` у `js/lang/*.js`.
Кнопка на панелі форм з'явиться сама.

Допоміжні: `shapeCells(name, from, to, opt)`, `shapeHeading(cells)` (напрям
`{dx, dy}` для стрічок).

## Спільні поля опису (tool і building)

```js
{
  id: 'belt',
  hud: { name: 'tool.belt', desc: 'tool.belt.desc', icon: '»' },
  cost: 240,
  sound: 'pickTool',
  levels: [ { interval: 3 }, { cost: 360, interval: 2 } ],
  reset, tick(frame), drawWorld(), overlay(mouseWorld),
  ghost: { size: 1, free: (mat) => bool }
}
```

- `hud` — ключі словника (текст ніколи не пишемо в код) та іконка-гліф.
  `desc` показується в меню E, коли елемент відкритий.
- `cost` — ціна покупки. **Немає `cost` = стартовий** елемент, відкритий з
  початку.
- `sound` — звук вибору: ключ у `SOUNDS`. Усі звуки, зокрема власні звуки
  елемента, описуються в `SOUNDS` у `js/sound.js`; файл елемента лише називає
  їх ключами.
- `levels` — масив рівнів. `levels[0]` — базовий, далі `{ cost, ...статистика }`.
  Поточну статистику читаємо через `pieceStats(id)`; апгрейд — `upgradePiece(id)`
  (кнопка «▲» на картці в меню E). Рівні скидаються разом із `resetToolbelt`.
- `reset()` — скинути стан елемента (новий світ).
- `tick(frame)` — щокадра симуляції (рух стрічок, охолодження запалу).
- `drawWorld()` — малювання в світі (стрічки, зона забору).
- `overlay(mouseWorld)` — малювання, коли елемент вибраний (підказка руки,
  прев'ю будівлі).
- `ghost` — квадрат під курсором; без поля курсор не малюється.

## Tool

Реєструється `regTool({...})`. Поведінка — одним з хуків, які викликає
`useTool` у `game.js`:

| Хук | Коли |
|---|---|
| `press(wpt)` | кадр натискання ЛКМ |
| `hold(wpt)` | ЛКМ утримується |
| `idle(wpt)` | кнопка не натиснута |
| `use(wpt)` | повний контроль (так працюють будівлі) |
| `grips: true` | елемент тримає підібраний об'єкт, поки затиснута ЛКМ |

Уся логіка, специфічна для інструмента (`drillAt`, `igniteAt`, `handPress`,
константи, власний стан), живе в його файлі.

## Building

Реєструється `regBuilding({...})` — додає `use`, `select`, `overlay` і `ghost`.
Додаткові поля:

| Поле | Значення |
|---|---|
| `shapes` | дозволені форми; перша — типова |
| `vertical` | чи дозволена вертикаль у `line` |
| `max` | ліміт клітин; перевищення → звіт `big` |
| `tint` | `{ ok, bad }` — кольори прев'ю |
| `arrows` | малювати стрілки напряму в прев'ю |
| `erasable` | ПКМ стирає клітини |
| `fits(plan)` | чи можна поставити |
| `place(plan)` | поставити; `plan = { cells, dx, dy }` |
| `done` / `big` | `{ text, sound }` — звіти для HUD |
| `owns(x, y)` | чи клітина належить цій будівлі (стирання, прев'ю) |
| `remove(x, y)` | прибрати побічний стан клітини (напр. напрям стрічки) |

Будівля — це клітини одного матеріалу плюс дані за індексом клітини (див.
`CLAUDE.md`, «World model»). Складених об'єктів немає.

## Як додати інструмент

1. Створити `js/PlayerInteract/Tools/Name.js`: функції поведінки + `regTool({...})`.
2. Додати `<script>` у `index.html` у потрібне місце порядку.
3. Додати в `js/lang/uk.js`, `en.js`, `pl.js`: `tool.<id>` і `tool.<id>.desc`.
4. `npm run lint:fix`.

## Як додати будівлю

1. Створити `js/PlayerInteract/Buildings/Name.js`: `fits`, `place`, за потреби
   `tick` / `drawWorld` / `owns` / `remove` + `regBuilding({...})`.
2. Матеріал будівлі — запис у `js/materials.data.js`.
3. `<script>` у `index.html`.
4. Словники: `tool.<id>`, `tool.<id>.desc`, `msg.<id>Done`.
5. `npm run lint:fix`.

## Як додати рівні

Додати `levels` у опис і читати `pieceStats(id)` там, де раніше була
константа. Ключі статистики — на розсуд елемента (`interval` у стрічки). Інше
(UI, ціна, збереження рівня) вже працює.

## Правила

- Ядро (`game.js`, `render.js`, `hud.js`, `input.js`) **не називає конкретних
  елементів**. Якщо хочеться написати там `if (tool === 'belt')` — потрібен
  новий хук у специфікації.
- Глобальна змінна змінюється лише у файлі, що її оголосив; стан елемента
  належить його файлу.
- Коментарів у коді немає; пояснення — тут, у README чи wiki.
